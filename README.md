This is a workout tracking app, primarily inspired by the UI and UX of another popular app called Strong.
Tech Stack: React Native, TypeScript, Expo, Supabase.

Development requires Node.js 22.13+ (22.x), 24.3+ (24.x), or 26+ and Expo SDK 58.
After upgrading the SDK, rebuild the development client before running the app.
EAS Update uses the native fingerprint as its runtime version so SDK 58 updates
are delivered only to compatible builds.

More details:
https://truegrind.netlify.app/
